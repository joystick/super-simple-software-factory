<p>A brand-new project has no existing tests to recon and no existing boundaries to interrogate — the adoption path here is different: think through the shape interactively first, make it a real repo with a minimal walking skeleton (something that runs end to end, even if it does almost nothing), then install SSSF and wire its gates to that skeleton before adding a single real feature. This lesson covers why skeleton-first beats feature-first for a from-scratch install, and how to run the first few slices one at a time so the roster and gates prove themselves against real, if small, work before you trust them with anything bigger.</p>
