The course on operating SSSF, consolidated from two source repos into one place. See
[Mission](/mission/) for objectives and [Notes](/notes/) for how this learner learns.

## Where the code these lessons are about actually lives

This directory holds course material only — no application code. Three repos are in play, and
most `[run]` steps depend on knowing which one to have open:

- **The Python playground repo** — the primary stamped SSSF repo. Chapters 1, 3, 4, 6, and 7 all
  run their `[run]` steps against it: skill source, stamped factory, the cart-pricing target app
  Chapter 1 uses, and — once you've worked through Chapter 3 — the queue infrastructure Chapters
  6–7 dispatch against.
- **The TypeScript rebuild repo** — Chapter 2 only. The Deno/TypeScript rebuild of the same
  pricing engine, with its own stamped factory, proving the gate discipline survives a change of
  toolchain.
- **An adoption target** — any existing codebase you bring yourself (or an empty directory for
  the new-project path). Chapter 3 is specifically about the situation where neither of the two
  repos above applies: a repo that was not built with a factory in mind, or doesn't exist yet.

Each chapter below names its own repo requirement explicitly in a "Check which repo you're
standing in" callout on its overview page — this section is the one-time summary, not a
substitute for reading those.

Both fixed repos remain independent, runnable projects. Nothing here duplicates their code —
only the teaching material has moved here.

## Chapters

The arc runs from a first gate you watch fail to a fully unattended dark-factory queue. Read in
order — each chapter after the second names exactly what it assumes from the ones before it,
rather than re-explaining:

- **[Chapter 1 — SSSF Fundamentals](/01-sssf-fundamentals/lessons/0000-agent-proposes-code-disposes/)**
  — the guarantee itself: gates, envelopes, phases, the fix loop, the trace. Builds the vocabulary
  every later chapter uses without re-explanation.
- **[Chapter 2 — Gates, Deep Dive](/02-gates-deep-dive/lessons/0001-three-gates-you-have-watched-fail/)**
  — re-proves Chapter 1's guarantee in a second language (TypeScript/Deno) end to end, so the
  lesson is shown to survive a change of toolchain rather than being an artifact of one. Assumes
  Chapter 1's vocabulary (gate, envelope, `quality.py`, "watched failing") without re-explaining
  it.
- **[Chapter 3 — Adopting a Factory](/03-adopting-a-factory/)** — the other situation you will
  actually be in: a repo that already exists and wasn't built for a factory, or doesn't exist
  yet. Follows the adoption playbook's Part A (existing codebase) and Part B (new project).
  Assumes Chapter 1's vocabulary and Chapter 2's toolchain-independence point.
- **[Chapter 4 — Coding Agents and Cost](/04-coding-agents-and-cost/)** — opens the coding-agent
  black box Chapter 1 left closed: what `coding_agent:` actually selects, what one headless turn
  can see and remember, where `total_tokens`/`total_cost` come from. Assumes Chapter 1's
  `AgentCall`/envelope/fix-loop/trace vocabulary.
- **[Chapter 6 — Going Dark](/06-going-dark/)** — the adoption playbook's Part C: getting one
  `just sdlc` run safe to leave unattended. Assumes Chapter 3's four jobs (the adoption
  vocabulary) and Chapter 4's driver contract (why `--system-prompt` replaces rather than
  appends, why `--setting-sources ''` matters for a headless node).
- **[Chapter 7 — The Queue](/07-the-queue/)** — the capstone. Puts a queue in front of Chapter 6's
  single unattended run: the dark-factory chain from an interactive interview through triage and
  into `just watch`'s scan-claim-dispatch-resolve loop. Assumes Chapter 6's bootstrap vocabulary
  and two-headless-problems lessons directly, plus a wired factory from Chapters 1–4.

(There is no Chapter 5 in the numbering — its one lesson was folded into Chapter 1 as lesson
0012, since a single-lesson chapter was creating a false expectation about its size.)

See also: [Resources](/02-gates-deep-dive/resources/) (Chapter 2's external sources).
