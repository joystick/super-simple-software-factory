<p>SSSF's `coding_agent` field selects between drivers — `agent_cc`, `agent_pi`, and others — that all sit behind one contract, so a chain's phases never need to know or care which one is actually running. This lesson covers what that contract requires of a driver (structured output, a usage/cost report, tool-call tracking) and why keeping drivers interchangeable behind it is what lets you swap `claude_code` for `pi` on one agent without touching the rest of the roster or a single phase definition.</p>
