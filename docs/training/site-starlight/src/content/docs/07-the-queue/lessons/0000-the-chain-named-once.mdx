<p>The full dark-factory chain is five steps, named once so every later lesson in this chapter can point back to a single ordered list instead of re-deriving it: `/grill-with-docs` (interactive, commits `CONTEXT.md`/`docs/adr/`), `/to-spec` (synthesizes the spec), `/to-tickets` (slices it into tickets), `/triage` (the only thing allowed to promote a ticket to `ready-for-agent`), and `just watch` (the headless scan-claim-dispatch-resolve loop covered in this chapter's `just watch` lesson). This lesson introduces the chain end to end before the following lessons go deep on any one link — commit the checkpoints and the mandatory-checks step between (4) and (6), covered next.</p>
