<p>This chapter's capstone puts the whole named chain to work on real, if small, work: run `/grill-with-docs` on a genuine new concept, carry it through `/to-spec` and `/to-tickets`, hand the result to `/triage`, run every mandatory checkpoint from the filing lesson before proceeding, then run `just watch --once` and read the result — a resolved ticket with a session id and commit pointer on success, or a ticket flipped to `ready-for-human` with a comment explaining exactly what broke on failure. The point of the capstone is watching the entire dark-factory loop complete for real, end to end, on a ticket you filed yourself, rather than trusting any single piece of it in isolation.</p>
